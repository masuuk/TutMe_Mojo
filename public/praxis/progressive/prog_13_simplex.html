Simplex over the Feasible Region

Learn by doing. Start with one objective value and progressively move toward constraints, slack, corner-point evaluation and the entering-variable rule.

Core concept: An LP is a linear objective plus linear constraints. The feasible region is a polytope and the optimum sits at a corner. Each simplex pivot walks one edge to a better corner; with x₁ + x₂ ≤ 6 and 2x₁ + x₂ ≤ 8, the optimum of Z = 4x₁ + 3x₂ is (2, 4) with Z = 20.

1Level 1 — The Objective at a Point

BeginnerObjective

Challenge: What is printed?

def main():
    var x1 = 1.0
    var x2 = 1.0
    print(4.0 * x1 + 3.0 * x2)
Only the objective runs here — no feasibility check in the code. Drop x₁ and x₂ straight into Z = 4x₁ + 3x₂ and add up the weighted contributions.
Solution 
7.0

Z = 4x₁ + 3x₂ at (1, 1) is 4 + 3 = 7. The objective tells you how good a point is; the constraints decide whether you are allowed to use it.

2Level 2 — Both Constraints at the Optimum

Beginner+Constraints

Challenge: What are the two constraint values at (x₁, x₂) = (2, 4)?

def main():
    var x1 = 2.0
    var x2 = 4.0
    print(x1 + x2)
    print(2.0 * x1 + x2)
Evaluate the two left-hand sides as ordinary sums — each prints one number. Given the point, both values should land exactly on their constraint limits.
Solution 
6.0
8.0

x₁ + x₂ = 6 and 2x₁ + x₂ = 8 — exactly the two limits. A vertex where every constraint is binding like this is where LPs get solved.

3Level 3 — Feasibility

IntermediateFeasible Region

Challenge: What is printed for x₁ = 5, x₂ = 2, and is the point feasible?

def main():
    var x1 = 5.0
    var x2 = 2.0
    print(x1 + x2)
The program prints a plain sum; feasibility is decided by the given bound, not by the code. Compare the printed sum against the ≤ 6 cap to answer both parts.
Solution 
7.0

x₁ + x₂ = 7, but the constraint is ≤ 6 — violated, so (5, 2) sits outside the feasible region and must be rejected no matter how high its objective.

4Level 4 — Slack Variables

Intermediate+Slack

Challenge: At the optimum (2, 4), how much of each resource is left over? (slack₁ = 6 − (x₁+x₂), slack₂ = 8 − (2x₁+x₂))

def main():
    var x1 = 2.0
    var x2 = 4.0
    var s1 = 6.0 - (x1 + x2)
    var s2 = 8.0 - (2.0 * x1 + x2)
    print(s1, s2)
Slack is defined as limit minus usage. At (2, 4) each constraint binds exactly, so each slack is the difference of two equal numbers.
Solution 
0.0 0.0

Both constraints bind exactly, so both slacks are 0 — no capacity is wasted. That is why both resources carry a shadow price at the optimum.

5Level 5 — Corner-Point Sweep

AdvancedVertices

Challenge: The feasible corners of this LP are (0,0), (4,0), (0,6), (2,4). What is the best Z found by this sweep?

def main():
    var z1 = 4.0 * 0.0 + 3.0 * 0.0   # (0, 0)
    var z2 = 4.0 * 4.0 + 3.0 * 0.0   # (4, 0)
    var z3 = 4.0 * 0.0 + 3.0 * 6.0   # (0, 6)
    var z4 = 4.0 * 2.0 + 3.0 * 4.0   # (2, 4)
    var best = z1
    if z2 > best:
        best = z2
    if z3 > best:
        best = z3
    if z4 > best:
        best = z4
    print(best)
Track best across the four updates — it only changes when a candidate beats the current winner. Compute the four Z values and keep the largest one.
Solution 
20.0

Z at the corners: 0, 16, 18, 20 — the best is 20 at (2, 4). By the fundamental theorem of LP the optimum lies at a corner, so simplex never searches the interior.

6Level 6 — Expert Challenge

AdvancedCode Reasoning Modification

Challenge: The initial tableau's objective row holds the negated costs [−4, −3] for x₁, x₂. Complete the loop that applies Dantzig's rule — enter the column with the MOST negative reduced cost. What column (1-based) enters?

from std.collections import List

def main():
    var reduced = List[Float64](-4.0, -3.0)
    var enter = 0
    for i in range(1, len(reduced)):
        pass                     # your line
    print(enter + 1)
Dantzig's rule scans for the most negative reduced cost. The two candidates are −4 and −3, and the loop compares each against the current enter; your answer is the 1-based column index, not the value itself.
Solution 
Possible solution

for i in range(1, len(reduced)):
    if reduced[i] < reduced[enter]:
        enter = i
print(enter + 1)   # 1

Dantzig's rule picks the column whose reduced cost is most negative: −4 beats −3, so x₁ (column 1) enters the basis first. The ratio test then decides which basic variable leaves — the pivot that walks the simplex to the next corner.
