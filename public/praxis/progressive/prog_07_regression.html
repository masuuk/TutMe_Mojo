Covariance & the Regression Line

Learn by doing. Start with paired deviations and progressively move toward covariance, the slope, the intercept and prediction.

Core concept: The least-squares line ŷ = a + bx has slope b = Σ(x−x̄)(y−ȳ) / Σ(x−x̄)² and intercept a = ȳ − b·x̄. Prediction is just substitution.

1Level 1 — Deviation Products

BeginnerBuild-up

Challenge: For pairs (1,2) and (3,6) with x̄ = 2 and ȳ = 4, what is Σ(x−x̄)(y−ȳ)?

def main():
    # deviations: x -> [-1, 1], y -> [-2, 2]
    var sxy = (-1.0 * -2.0) + (1.0 * 2.0)
    print(sxy)
The comment already lists the deviations — multiply each matching x-y pair and add the two products.
Solution 
4.0

The products are (−1)(−2) = 2 and (1)(2) = 2; they sum to 4 — positive co-movement.

2Level 2 — Squared x-Deviations

Beginner+Denominator

Challenge: What is Σ(x−x̄)² for x = 1, 3?

def main():
    var sxx = (-1.0 * -1.0) + (1.0 * 1.0)
    print(sxx)
Only the x side matters here: square each deviation (−1 and +1) and add them.
Solution 
2.0

The x-deviations are −1 and +1; their squares sum to 2. This is the spread the slope divides by.

3Level 3 — The Slope

IntermediateSlope

Challenge: What is printed?

def main():
    var sxy = 4.0
    var sxx = 2.0
    print(sxy / sxx)
The slope is plain division of the two accumulated numbers from Levels 1 and 2 — no units, no extra steps.
Solution 
2.0

Slope b = Sxy / Sxx = 4 / 2 = 2: each extra unit of x predicts two extra units of y.

4Level 4 — The Intercept

Intermediate+Intercept

Challenge: With b = 2, x̄ = 2 and ȳ = 4, what is the intercept a = ȳ − b·x̄?

def main():
    var b = 2.0
    var xbar = 2.0
    var ybar = 4.0
    print(ybar - b * xbar)
Substitute the three given numbers into a = ȳ − b·x̄ and do the multiplication before the subtraction.
Solution 
0.0

a = 4 − 2·2 = 0, so the fitted line is ŷ = 2x. It passes exactly through the mean point (2, 4) — as least-squares lines always do.

5Level 5 — Prediction

AdvancedPrediction

Challenge: Using ŷ = 2x, what is printed for x = 5?

def main():
    var a = 0.0
    var b = 2.0
    var x_new = 5.0
    print(a + b * x_new)
Plug x = 5 into ŷ = 2x — a single multiplication followed by adding zero.
Solution 
10.0

Substitution: ŷ = 0 + 2·5 = 10. The fitted line turns any new x into a predicted y.

6Level 6 — Expert Challenge

AdvancedCode Reasoning Modification

Challenge: Complete the two marked lines so the program fits and prints the prediction for x = 5 from the data (1,2), (3,6). What is the final printed value?

from std.collections import List

def main():
    var xs = List[Float64](1.0, 3.0)
    var ys = List[Float64](2.0, 6.0)
    var xbar = 2.0
    var ybar = 4.0
    var sxy = 0.0
    var sxx = 0.0
    for i in range(len(xs)):
        var dx = xs[i] - xbar
        sxy += dx * (ys[i] - ybar)   # your line 1
        sxx += dx * dx               # your line 2
    var b = sxy / sxx
    var a = ybar - b * xbar
    print(a + b * 5.0)
Reuse Levels 1–4: accumulate Sxy and Sxx inside the loop, then compute b and a before the print. The final value is the same 10 from Level 5.
Solution 
Possible solution

for i in range(len(xs)):
    var dx = xs[i] - xbar
    sxy += dx * (ys[i] - ybar)
    sxx += dx * dx
var b = sxy / sxx
var a = ybar - b * xbar
print(a + b * 5.0)   # 10.0

The loop accumulates Sxy = 4 and Sxx = 2, giving b = 2 and a = 0, so ŷ(5) = 10.0. Every level of this drill was one line of this final program.
