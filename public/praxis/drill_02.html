Drill 02 · Coordinate Distance

Model two 2D points and calculate their Euclidean distance.

Your task

Create a Point struct, then write a distance function. Test (0,0) → (3,4) and explain why the answer is 5.

Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

What is the Euclidean distance between (0, 0) and (3, 4)?

Why: √(3² + 4²) = √25 = 5 — a 3-4-5 triangle.
Solution

A reference implementation in Mojo — compare once you have written it yourself.

struct Point:
    var x: Float64
    var y: Float64

    def __init__(out self, x: Float64, y: Float64):
        self.x = x
        self.y = y

def distance(a: Point, b: Point) -> Float64:
    return ((a.x - b.x) ** 2 + (a.y - b.y) ** 2) ** 0.5

def main():
    var p0 = Point(0.0, 0.0)
    var p1 = Point(3.0, 4.0)
    print(distance(p0, p1))  # 5.0
