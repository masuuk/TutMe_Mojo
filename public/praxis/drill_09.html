PRAXIS · CH 07

Drill 09 · Ownership & References

Write functions that take values by default, `mut` and `var`, and reason about who owns what.

Your task

Write `def add(mut x: Int, y: Int): x += y` and call it from `main` — confirm mutation persists only on the `mut` argument. Create a `String` and a function that takes it by `var` (owned), transfer it with `^`, then confirm the source is no longer usable. Add a function returning a `ref` and explain its lifetime rule. Use `origin_of()` on a binding to read its origin.

Based on Chapter 7 · Ownership, References & Value Semantics. Do the problem before looking for a solution or answering the checkpoint. If you forget syntax, use the Mojo Library.

Checkpoint · multiple choice

When a function parameter is declared `mut x: Int`, what does mutating `x` inside the function do to the caller?

Why: `mut` (like `inout`) is a mutable reference: the function sees and can modify the caller's storage, and the change survives the call.
Solution

Reference code demonstrating arguments by value, `mut`, `var` (owned), and `ref` bindings.

def add(mut x: Int, y: Int):
    x += y               # mut: caller sees the change

def consume(var s: String):
    print(s)             # owned - may transfer/mutate freely

def double() -> Int:
    var c = 21
    ref r = c            # ref binding aliases c
    r *= 2
    return c             # 42

def main():
    var a = 1
    add(a, 2)            # a becomes 3 (mut)
    print(a)             # 3

    var s = String("owned value")
    consume(s^)          # s is transferred out
    # print(s)           # ERROR - no longer owned here

    var r = double()
    print(r)

    # origin_of(b) (ch07) is a compile-time helper for threading
    # lifetimes through signatures - not a printable runtime value.
