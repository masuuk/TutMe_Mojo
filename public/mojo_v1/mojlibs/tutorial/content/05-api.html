Designing the public API

A public API is not a place to dump everything you know. It is a place to communicate clear assumptions. The best library APIs are narrow, explicit, and hard to misuse.

  • Semantic names. Prefer normal_cdf over a vague cdf.
  • Unit-bearing names. Prefer bearing_deg over an ambiguous bearing.
  • Violations raise. Empty data, mismatched lengths, and invalid probabilities should fail loudly.
