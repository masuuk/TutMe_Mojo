Exercises

If you want to learn this material by doing it, start with the following tasks.

  • Add a trimmed_mean helper to the statistics package and test it on symmetric and skewed data.
  • Add a traverse validation report in geomatics that rejects closure errors above tolerance.
  • Extend the finance package with a value_at_risk function that matches a specified confidence level.
  • Implement a simple queueing or scheduling model in the operations research package.
  • Build a first-order time-series smoother in the analytics package and test it against a known trend line.

Each of these is a library-sized problem, but each one is also a good way to learn how a small API grows into a real domain tool.
