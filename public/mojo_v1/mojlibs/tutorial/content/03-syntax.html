The conventions that make the code readable

Mojo 1.1 uses a small, direct syntax. In this tutorial we treat the following as the baseline:

  • def defines a function.
  • var is the mutating variable declaration; comptime is used for compile-time values.
  • Argument conventions are written as mut, var, ref, out, and deinit where needed.
  • Libraries expose a stable interface through package re-exports, not by leaking internal implementation details.
