Fundamentals of Programming with Mojo

An introduction to computer programming. Start with the machine — bits, bytes, memory, and the CPU — then learn to command it with Mojo, a compiled language. Every example follows the official Mojo 1.x reference: def, var, mut/out, and the typed collections (List, Dict, Set) from the collections module.

1. How Computers Work

Before writing a single program, meet the machine. At the bottom of every computer is one idea: it stores and manipulates two values. Everything else — numbers, letters, pictures, sound, the page you are reading — is a layer of meaning built on top.

Bits & bytes

A bit (short for binary digit) is the smallest unit of information: a switch that is either off or on. We write those two states as 0 and 1. Inside a modern processor there are billions of microscopic switches that flip between them billions of times per second.

Bits are grouped to carry more meaning: 8 bits make one byte. A byte can represent 28 = 256 different patterns, counted as 0 through 255. Each bit position is worth a power of two:

128 64 32 16 8 4 2 1 # place value 1 1 0 0 0 1 1 0 # the bits 11000110 # 11000110 = 128 + 64 + 4 + 2 = 198

Binary counting looks strange at first: 0, 1, 10, 11, 100, 101, 110, 111. After 1 you carry over, just as decimal counting carries after 9. With enough bytes you can represent any number, any text, any image. The work is always in the interpretation: the byte 01000001 might be the integer 65, the letter A, or one red channel of a pixel, depending on context.

Bytes scale up quickly: a kilobyte (KB) is roughly a thousand bytes, a megabyte (MB) a million, a gigabyte (GB) a billion. This page of text is a few KB; a photo is a few MB; an hour of video can be several GB.

Bytes as characters

Text was one of the first things people agreed to encode. A convention called ASCII maps each common character to a byte value:

CharacterDecimalBinary
!3300100001
04800110000
A6501000001
B6601000010
a9701100001

So the word Hello is simply the byte sequence 72 101 108 108 111. When your program prints text, it is really writing 0s and 1s that the device decodes back into letters.

Memory

A running program needs a place to keep its data. Random‑access memory (RAM) is a long row of byte‑sized boxes, each with a numbered address. The CPU can read or write any box by address:

address value meaning 1000 72 "H" 1001 101 "e" 1002 108 "l" 1003 108 "l" 1004 111 "o"

Both your program's code and its data live in memory while it runs. RAM is fast but volatile — it forgets everything when the power goes off. That is why you also have storage (a hard drive or SSD), which keeps files even when the machine is off. A program on disk is loaded into RAM, then executed from there.

The CPU

The central processing unit (CPU) executes instructions one at a time in a fetch‑decode‑execute cycle: it fetches the next instruction from memory, decodes what it means, and executes it. Instructions are tiny operations — load a byte, add two numbers, compare values, jump to another part of the program when a comparison is true. A 3 gigahertz CPU carries out roughly three billion of these cycles per second.

Loops, decisions, and function calls are not magic — they are combinations of jumps and comparisons that a programmer's words describe.

From human to machine

Nobody wants to write 01000001 by hand. A programming language lets humans express logic in words, and a compiler translates those words into the exact bytes a CPU understands. Mojo is such a compiled language: when you run mojo run, the source is compiled and only then does the CPU execute it. The rest of this book teaches you to write that source.

🔹 Three things to remember: a bit is 0 or 1, eight bits make a byte, and a byte's meaning depends on the context that interprets it.

2. Hello, Mojo

Chapter 1 ended with how a computer runs a program: the compiler turns source text into instructions, and the CPU carries them out. Let's write such a program. Mojo is a statically typed compiled language, which means every value has a type the compiler checks before the program runs.

def main(): print("Hello, Mojo 1.x!") var x: Int = 42 print("The answer is", x)

Running this file compiles it and runs main(). Every program defines def main(): as its entry point.

✦ In Mojo 1.x there is one function keyword: def. A def with typed annotations is compiled to native code. Variables use var.

3. Variables & Types

Mojo is statically typed but supports type inference. Every binding uses var.

var name: String = "Mojo" # String var version = 1.0 # Float64 inferred var counter: Int = 0 # mutable counter += 1 var is_fast: Bool = True var pi: Float32 = 3.14159 var byte: UInt8 = 255

Built‑in scalar types include Int, Float32, Float64, Bool, String, and fixed‑width unsigned types such as UInt8/UInt16. Numbers convert explicitly — Mojo never converts implicitly:

var n: Int = 10 var x: Float64 = Float64(n) # explicit conversion

Constant values that must be known at compile time use comptime. It can never change at runtime:

comptime MAX_ITER = 100 # compile-time constant
⚡ Prefer comptime for compile‑time constants and var for runtime bindings. Read‑only access (sharing a value without copying) is expressed with ref — see Chapter 10.

4. Control Flow

Programs decide and repeat. Both are compound statements — a header line ending in : followed by an indented body. Mojo branches with the if/elif/else statement and loops with the for and while statements, plus continue (skip this iteration) and break (leave the loop) to steer them. The example below shows each in action; the sections that follow take the loop statements in depth.

var x = 10 if x > 5: print("x is large") elif x < 0: print("x is negative") else: print("x is small") # for loop over a range for i in range(5): print("i =", i) # while loop var n = 3 while n > 0: print("n =", n) n -= 1 # continue / break for i in range(10): if i == 3: continue if i == 6: break print(i) # 0 1 2 4 5

Computers earn their keep by repeating. A loop runs a block of code once per element or once per condition — and everything else a program does (searching, summing, retrying, simulating) is a loop wearing a different coat. Mojo has two loop statements: for (once per item) and while (once per condition), plus break and continue to steer them — and a compile-time variant, comptime for, that unrolls its body into separate code before the program ever runs.

4.1 for: once per item

A for loop walks anything iterable: a range of numbers, a List, or the List that split() returns. The loop variable is an immutable reference by default — you can read it, not write it.

for i in range(3): # 0, 1, 2 — range(3) excludes 3 print(i) var names: List[String] = ["ada", "grace", "linus"] for name in names: # iterate any List print("hello,", name) for part in "a,b,c".split(","): # split() hands back an iterable List print(part)

Need to modify items as you go? Ask for a mutable copy with for var item in xs, or write straight back into the collection with for ref item in xs — the same ownership conventions you will meet again in ref bindings (Chapter 10).

4.2 while: once per condition

A for loop knows how many steps it will take; a while loop does not — it runs until its condition turns false. That is exactly right when the trip count is discovered along the way: countdowns, retry logic, numerical iteration until convergence.

var n = 5 while n > 0: print(n) n -= 1 # the update is the whole trick — forget it and the loop never ends print("liftoff")

4.3 break and continue

break leaves the loop immediately; continue skips to the next iteration. Together they keep loop bodies flat: instead of wrapping everything in an if, you exit early.

for i in range(100): if i % 2 == 1: continue # odd? skip it if i > 8: break # past 8? we are done print(i) # prints 0 2 4 6 8

4.4 The three classic patterns

Nearly every loop you will ever write is one of three shapes. Learn them here and you will recognise them everywhere — including inside the Series program of Chapter 13.

# 1. Accumulate — fold many values into one var total = 0 for x in [120, 132, 145]: total += x # 397 # 2. Search — stop at the first match var found = -1 for i in range(len(names)): if names[i] == "grace": found = i break # 1 — no need to keep looking # 3. Nested — a loop inside a loop walks a grid for row in range(3): for col in range(3): print(row, col) # all nine pairs, row by row

⚡ Prefer for when you can — it cannot run forever. Reach for while only when the number of trips is genuinely unknown ahead of time, and always make sure something inside the body moves the condition toward false.

5. Functions (def)

Every function is a def. Type annotations are optional, but they unlock native compilation, better errors, and safer code.

# typed function def add(a: Int, b: Int) -> Int: return a + b # default arguments def greet(name: String = "world"): print("Hello,", name) # multiple returns use destructuring def minmax(a: Int, b: Int) -> Int: return a if a < b else b def main(): var total = add(3, 4) # 7 print(total) greet("Mojo") # Hello, Mojo

The full signature grammar: parameters and return type first, then the raises effect if the function can throw:

def invert(x: Float64) raises -> Float64: # body return 1.0 / x

6. Parameters & Generics

Mojo separates parameters (compile time, in [...]) from arguments (runtime, in (...)). Parameters let the compiler specialize code before it runs — the compiler works on your behalf.

# N is a compile-time parameter; value arrives at runtime def expand[N: Int](value: Int) -> Int: var total: Int = 0 for i in range(N): total += value return total def main(): print(expand[5](3)) # 15

Generic functions accept any type that satisfies a trait constraint. Here Intable means "convertible to Int":

def identity[T: Intable](x: T) -> Int: return Int(x) def main(): print(identity(42)) # 42 print(identity(7.5)) # 7

Traits can be composed with & to require several capabilities, and comptime members make constants part of a type's contract (see Chapter 8).

7. Structs & Methods

A struct defines a value type with methods — like a class in an object-oriented language, but without inheritance. Fields are declared with var.

from std.math import sqrt struct Point: var x: Float64 var y: Float64 def __init__(out self, x: Float64, y: Float64): self.x = x self.y = y def move_by(mut self, dx: Float64, dy: Float64): self.x += dx self.y += dy def distance(self, other: Point) -> Float64: var dx = self.x - other.x var dy = self.y - other.y return sqrt(dx * dx + dy * dy) def main(): var p1 = Point(0.0, 0.0) var p2 = Point(3.0, 4.0) print(p1.distance(p2)) # 5.0 p1.move_by(1.0, 1.0) print(p1.x) # 1.0
🔹 Method receivers say what they do: __init__ uses out self, mutating methods use mut self, and read‑only methods use plain self.

When every field is initialized from a parameter, the @fieldwise_init decorator synthesizes the initializer for you:

@fieldwise_init struct Pixel: var r: UInt8 var g: UInt8 var b: UInt8 def main(): var px = Pixel(255, 0, 0) # a red pixel

Self names the enclosing type inside a struct — handy for returning a new instance:

struct Meters: var value: Float64 def __init__(out self, value: Float64): self.value = value def scaled(self, factor: Float64) -> Self: return Self(self.value * factor) def main(): var m = Meters(10.0) print(m.scaled(2.0).value) # 20.0

8. Traits

A trait describes a capability. Conforming structs must implement its required methods; the compiler checks every conformance.

trait Shape: def area(self) -> Float64: ... # required def describe(self) -> String: # provided return "a shape" @fieldwise_init struct Circle(Shape): var radius: Float64 def area(self) -> Float64: return 3.141592653589793 * self.radius * self.radius def describe(self) -> String: return String(t"a circle of radius {self.radius}") @fieldwise_init struct Square(Shape): var side: Float64 def area(self) -> Float64: return self.side * self.side def print_area[T: Shape](shape: T): print(shape.describe(), "=>", shape.area()) def main(): print_area(Circle(2.0)) # a circle ... => 12.566... print_area(Square(3.0)) # a shape => 9.0

In a trait body, ... marks a required method — conforming types must implement it. A method with a real body is a provided default. Traits may include comptime members: associated types, required values, and constants. Static methods use @staticmethod:

struct MathUtils: @staticmethod def square(x: Int) -> Int: return x * x def main(): print(MathUtils.square(9)) # 81

9. Collections

Everyday data lives in the std.collections module — bring it in with from std.collections import List, Dict, Set — and display literals build the values directly.

from std.collections import List, Dict, Set var evens: List[Int] = [2, 4, 6, 8] evens.append(10) # grows the list # read elements print(evens[0]) # 2 print(len(evens)) # 5 # iterate by value for value in evens: print(value) # iterate by index for i in range(len(evens)): print(evens[i])
var ages: Dict[String, Int] = {"Ada": 36, "Grace": 33} print(ages["Ada"]) # 36 ages["Lin"] = 32 # insert or update # iterate entries (key, value) for entry in ages.items(): print(entry.key, "-", entry.value)
📚 List and Dict are generic: List[Float64], Dict[String, List[Int]]. Use var xs: List[Int] = [] for an empty collection.

10. Ownership & Conventions

Mojo is memory‑safe without garbage collection. Every argument declares how it joins the function — the convention appears before the argument name. With no convention, the argument is an immutable read‑only reference and the caller keeps ownership. The options:

ConventionMeaning
(imm) — defaultImmutable read‑only reference; caller keeps ownership.
mutRead‑write reference; changes are visible to the caller.
varOwned copy (or a move when passed with ^).
outThe function's return slot; replaces ->.
deinitTakes ownership and destroys the value (self in __deinit__).
refReference with an explicit origin specifier.
# default (imm): read-only, no copy def length[T: Copyable](s: List[T]) -> Int: return len(s) # mut: changes reach the caller def double_it(mut x: Int): x *= 2 # var: owned copy (or move with ^) def consume(var s: String): s += "!" print(s) # out: return slot instead of -> def make_int(out result: Int): result = 42 def main(): var n = 5 double_it(n) # mutated in place print(n) # 10 var greeting = "Hello" consume(greeting) # Hello! (copied) consume(greeting^) # Hello! (moved; greeting unusable after) var x = make_int() # out fills the return slot print(x) # 42

11. Errors & Testing

A function that can fail declares raises. Use raise Error(...) to signal failure and try / except to handle it.

def parse_level(text: String) raises -> Int: if text == "low": return 1 if text == "high": return 3 raise Error("unknown level") def main(): try: var level = parse_level("mid") print(level) except e: print("Error caught:", e)

Tests are plain functions. assert verifies a condition; with -D ASSERT the checks are compiled out of release builds:

def add(a: Int, b: Int) -> Int: return a + b def test_add(): assert(add(2, 3) == 5) assert(add(-2, 2) == 0) print("add passes")

12. Python Interop & Compilation

Mojo can run Python code too. Import any Python package with Python.import_module and use it directly:

from std.python import Python def main(): var np = Python.import_module("numpy") var data = np.random.randn(1000) print("mean:", np.mean(data)) print("std :", np.std(data))

Template strings (the t prefix) interpolate values at runtime and are the idiomatic way to build output:

var name = "Ada" print(t"Hello, {name}!") # Hello, Ada!

Remember what compilation means from Chapter 1, now in practice: typed def functions are compiled, comptime work happens before the program runs, and parameters make the compiler generate a specialized copy of a generic function for each usage. What you write is essentially what the processor executes.

13. A Small Program

A running example that ties the course together: a Series struct that records values and reports their mean and standard deviation.

from std.math import sqrt struct Series: var data: List[Float64] def __init__(out self): self.data = [] def push(mut self, x: Float64): self.data.append(x) def mean(self) -> Float64: var total = 0.0 for x in self.data: total += x return total / Float64(len(self.data)) def stddev(self) -> Float64: var m = self.mean() var total = 0.0 for x in self.data: total += (x - m) * (x - m) return sqrt(total / Float64(len(self.data))) def main(): var s = Series() for i in range(8): s.push(Float64(i)) print("mean =", s.mean()) print("stddev =", s.stddev())

After this chapter you have used: struct and methods, def signatures with out self/mut self, List with append, for loops, explicit type conversion, and t"..." output. That is a complete programming loop in Mojo 1.x.

Series exercises (Chapter 13)

Challenge 1 · median() — hint first

Sort a copy of the data first. With an odd count, the median is the middle value; with an even count it is the average of the two middle values. All you need is append, index read and write, len, %, and the >> shift to halve — no library call.

Solution. Add this method to Series:

def median(self) -> Float64:
    # copy the data first so the original stays untouched
    var s: List[Float64] = []
    for x in self.data:
        s.append(x)

    # a simple selection sort — swaps the smallest value into place
    var n = len(s)
    for i in range(n):
        var smallest = i
        for j in range(i, n):
            if s[j] < s[smallest]:
                smallest = j
        if smallest != i:
            var tmp = s[i]
            s[i] = s[smallest]
            s[smallest] = tmp

    var mid = n >> 1
    if n % 2 == 1:
        return s[mid]
    return (s[mid - 1] + s[mid]) / 2.0

Check yourself: for the values 0…7 used in Chapter 13, the median is the average of 3 and 4. Build the series exactly as in that chapter — push each value in a loop — then s.median() should print 3.5. Your median() must leave self.data in push order; the method only sorts its own copy.

Challenge 2 · your own trait — hint first

Pick one capability both structs share. Declare it as a required method ending in ..., then put shared behavior in a provided method that calls the required one. Instances of either struct can then use both methods.

Solution. A trait that gives anything a printable greeting for free:

trait Named:
    # required: every conformance must provide this
    def name(self) -> String: ...
    # provided: shared behavior, built on the required method
    def greeting(self) -> String:
        return String(t"Hello, {self.name()}!")

@fieldwise_init
struct City(Named):
    var title: String
    def name(self) -> String:
        return self.title

@fieldwise_init
struct Robot(Named):
    var id: Int
    def name(self) -> String:
        return String(t"Robot-{self.id}")

def main():
    var c = City("Oslo")
    var r = Robot(7)
    print(c.greeting())   # Hello, Oslo!
    print(r.greeting())   # Hello, Robot-7!

Note the two sides of a trait: conforming structs are responsible for the ... methods; the rest of the behavior is written once and shared.

Project hints

Knowledge Checker — hint & starter

Keep three lists in parallel — questions, answers, guesses — and compare them by index. A score counter ticks up on each match. Extend it later by swapping the hard-coded guesses for real user input. 

var questions: List[String] = [
    "2 + 2 = ?", "4 * 3 = ?",
]
var answers: List[Int] = [4, 12]
var guesses: List[Int] = [4, 10]

var score = 0
for i in range(len(questions)):
    if guesses[i] == answers[i]:
        score += 1
        print(questions[i], "-> correct")
    else:
        print(questions[i], "-> missed")
print("score:", score, "of", len(questions))   # 1 of 2
Data Cleaner — hint & starter

Three passes: filter out invalid values, find the min and max in one scan, then rescale every value to 0…1 with (x - lo) / (hi - lo). 

var data: List[Float64] = [1.0, 2.5, 0.0, 9.0, 4.0]

# 1) keep only positive values
var clean: List[Float64] = []
for x in data:
    if x > 0.0:
        clean.append(x)

# 2) lowest and highest in one pass
var lo = clean[0]
var hi = clean[0]
for x in clean:
    if x < lo:
        lo = x
    if x > hi:
        hi = x

# 3) rescale to 0..1
var scaled: List[Float64] = []
for x in clean:
    scaled.append((x - lo) / (hi - lo))
print(scaled)   # [0.0, 0.2777, 1.0, 0.4444]
Budget Tracker — hint & starter

One Dict for income, one for expenses. Sum each dict's values with items(); the balance is income minus expenses. Add categories by inserting into the dicts. 

var income: Dict[String, Float64] = {"salary": 2400.0}
var expenses: Dict[String, Float64] = {
    "rent": 900.0,
    "food": 300.0,
}

var total_in = 0.0
for entry in income.items():
    total_in += entry.value

var total_out = 0.0
for entry in expenses.items():
    total_out += entry.value

print("saved:", total_in - total_out)   # 1200.0
Ride Fare Estimator — hint & starter

Wrap the pricing rules in a struct: a fixed base fare plus a rate per kilometer. Reject bad input with a raises method so the caller is forced to handle it. 

struct Ride:
    var distance: Float64
    var rate_per_km: Float64

    def __init__(out self, distance: Float64, rate_per_km: Float64):
        self.distance = distance
        self.rate_per_km = rate_per_km

    def fare(self) raises -> Float64:
        if self.distance < 0.0:
            raise Error("distance cannot be negative")
        return 2.0 + self.distance * self.rate_per_km

def main():
    var ride = Ride(10.0, 0.8)
    try:
        print(ride.fare())   # 10.0
    except e:
        print(e)
Mini Stats Library — hint & starter

Add min() and max() to Series, then reuse the median() solution above. For the slope you need paired (x, y) values: slope = Σ (x−μx)(y−μy) ÷ Σ (x−μx)², built from two means and one loop. 

struct Regression:
    var x: List[Float64]
    var y: List[Float64]

    def __init__(out self):
        self.x = []
        self.y = []

    def push(mut self, xi: Float64, yi: Float64):
        self.x.append(xi)
        self.y.append(yi)

    def slope(self) -> Float64:
        var n = Float64(len(self.x))
        var mx = 0.0
        for v in self.x:
            mx += v
        mx /= n
        var my = 0.0
        for v in self.y:
            my += v
        my /= n

        # slope = covariance / variance
        var num = 0.0
        var den = 0.0
        for i in range(len(self.x)):
            num += (self.x[i] - mx) * (self.y[i] - my)
            den += (self.x[i] - mx) * (self.x[i] - mx)
        return num / den
Python–Mojo Bridge — hint & starter

Let pandas do the parsing and hand the numbers to numpy for the math. Keep the data on the Python side — moving whole frames into Mojo goes beyond this book. 

from std.python import Python

def main():
    var pd = Python.import_module("pandas")
    var df = pd.read_csv("grades.csv")
    print(df.head())

    var np = Python.import_module("numpy")
    var scores = df["score"].to_list()
    print("mean:", np.mean(scores))
