Chapter 5

Operators & Control Flow

Arithmetic, comparison, bitwise and boolean operators — plus if, while, and for statements that structure your program's logic.

Mojo's operator syntax mirrors Python. Symbols, precedence, and associativity follow Python conventions, so most behavior feels familiar from Python, C, or Rust. A few details are specific to Mojo:

  • Boolean operators are words — and, or, not — never symbols like && or ||.
  • The ternary expression places the condition in the middle: a if cond else b.
  • The caret (^) serves double duty as bitwise XOR and the transfer sigil for ownership.

1. Arithmetic

print(7 + 3)   # 10, add
print(7 - 3)   # 4, subtract
print(7 * 3)   # 21, multiply

# Exponentiation uses two stars, not a caret
print(2 ** 8)  # 256

# Unary prefix operators
var a: Int8 = -128
print(~a)     # invert bits → 127
10
4
21
256
127
  • -x negates; +x is a no-op identity; ~x inverts bits.
  • If you prefer a function form for powers, call pow(base, exponent).

Two division operators

The difference matters for negative numbers:

var a = -7
var b = 4
print(a / b)    # -1  (truncates toward zero)
print(a // b)   # -2  (rounds toward negative infinity)
  • / — truncation toward zero.
  • // — floor division toward negative infinity.
  • For floating-point types, / performs standard division and // returns a float rounded down to the nearest whole number. Both keep the operands' result type.

The modulo operator % returns the remainder satisfying this invariant:

# a == b * (a // b) + (a % b)
print(7 % 3)    # 1
print(-7 % 4)   # 1
print(7 % -4)   # -1

Associativity & matrix multiply

** is right-associative — one of only two right-associative operators in Mojo, the other being the ternary conditional:

print(2 ** 3 ** 2)   # 512 — same as 2 ** (3 ** 2)

The @ operator performs matrix multiplication (NumPy-style). Mojo has no built-in matrix type, but any type implementing __matmul__() can use it.

⚠️ Watch Out:

Coming from Python: 7 / 2 gives 3 on integers — Mojo's / keeps the operand type instead of always producing a float. Write Float64(a) / Float64(b) when you want true division.

2. Comparisons

Six comparison operators — ==, !=, <, <=, >, >= — each returning a Bool:

print(10 > 5)     # True
print(10 == 10)   # True
print(10 != 10)   # False

Floating point: avoid ==

from std.math import isclose

var total: Float64 = 0.0
for _ in range(10):
    total += 0.1

print(total == 1.0)       # False!
print(isclose(total, 1.0)) # True

Chained comparisons

You can chain comparisons to check a range in one expression. The middle value is evaluated only once:

var x = 5
print(1 < x < 10)        # True — 1 < x and x < 10
print(1 < x <= 5 < 9)    # True

var items = [1, 2, 3, 4, 5]
var ok = 0 < len(items) <= 10   # len() called once
print(ok)                 # True
💡 Key Insight:

Comparison, membership, and identity operators share one precedence level, so they combine freely in a chain: a < b in c is d evaluates as (a < b) and (b in c) and (c is d).

3. Bitwise

Bitwise operators work on integer types — handy for flags, masks, and packing data:

print(12 & 10)    # 8   (1100 & 1010 = 1000)
print(12 | 10)    # 14  (1100 | 1010 = 1110)
print(12 ^ 10)    # 6   (1100 ^ 1010 = 0110)
print(1 << 4)     # 16  shift left
print(64 >> 3)    # 8   shift right

# Building a flag register
var perms: UInt8 = 0b0000
perms |= 0b0100    # set READ bit   → 0b0100
perms |= 0b0001    # set EXEC bit   → 0b0101
perms &= 0b0111    # keep low bits  → still 0b0101
print(perms)       # 5

Precedence within bitwise ops

From highest to lowest: unary ~, then shifts (<<, >>), then &, then ^, then |. Parenthesize when mixing groups.

⚠️ Watch Out:

x^+1 looks like exponentiation to C eyes, but it parses as x ^ (+1) — an XOR! Exponentiation is **. Use spaces around ^ to keep intent clear.

4. Boolean Logic

Logical operators are the keywords and, or, not:

var age = 25
var has_ticket = True

if age >= 18 and has_ticket:
    print("Enjoy the show")

if age < 12 or age >= 65:
    print("Discount applies")

if not has_ticket:
    print("Please buy a ticket")

Short-circuit evaluation

and stops at the first false operand; or stops at the first true one. The right-hand side may never run:

def check_stock() -> Bool:
    print("checking stock...")
    return True

var ok = False and check_stock()   # no output — RHS skipped
ok = True or check_stock()         # no output — RHS skipped

Truthiness

Conditions don't require an explicit == True. Any type implementing the Boolable trait converts to Bool in a condition. Falsy values:

  • False itself, and the integer/float value zero
  • An empty String ("")
  • Empty collections: List, Dict, Set
  • An Optional holding None

Everything else is truthy.

5. Membership & Identity

in / not in

var fruits = ["apple", "banana", "cherry"]

if "banana" in fruits:
    print("found banana")

if "grape" not in fruits:
    print("no grapes here")

# Strings support substring tests
if "nan" in "banana":
    print("substring!")

is / is not

The identity operators test whether two references designate the same object. Their most common use is checking against None:

var maybe: Optional[Int] = Optional(7)

if maybe is None:
    print("nothing stored")
else:
    print(maybe.value())   # 7

6. Operators on Strings

var full = "Mo" + "jo"       # concatenation → "Mojo"
var rule = "=" * 20          # repetition

# Prefer the constructor when joining many pieces:
var path = String("/home", "/", "user", "/notes")
print(path)

Chained + creates intermediate allocations; the multi-argument String() constructor sizes its buffer once.

Lexicographic ordering

Comparison operators order strings lexicographically by Unicode scalar values — uppercase letters sort before lowercase:

print("Zebra" < "ant")   # True — 'Z' (90) < 'a' (97)
🚀 Pro Tip:

For formatted string building, t-strings (t"...{value}...", covered in Chapter 3) stay lazy and allocation-free until you call String() on them.

7. Conditionals

if/elif/else work as in Python:

def grade_for(score: Int) -> String:
    if score >= 90:
        return "A"
    elif score >= 80:
        return "B"
    elif score >= 70:
        return "C"
    else:
        return "F"

print(grade_for(83))   # B
B

A one-line form works for single statements:

var temperature = 31
if temperature > 30: print("Stay hydrated")

The conditional expression (ternary)

Pick between two values inline. The condition sits in the middle, and the expression is right-associative like **:

var age = 20
var ticket = "adult" if age >= 18 else "child"
print(ticket)

# Usable anywhere an expression fits:
print("even" if age % 2 == 0 else "odd")
adult
even
💡 Key Insight:

Mojo does not yet have a match or switch statement — it's on the language roadmap. Chain if/elif for now.

To modify elements while iterating, request a mutable reference with for ref:

var values = [1, 2, 3]
for ref v in values:
    v += 10                   # writes through the reference
print(values[0])             # 11

break & continue

for i in range(10):
    if i == 3:
        continue   # skip 3
    if i == 6:
        break      # exit loop entirely
    print(i)

The for/else clause

The else block runs after the loop completes all iterations — including when the collection is empty. It is skipped only if the loop exits via break (or a return). Classic use: search loops.

var haystack = [4, 8, 15]

for target in [8, 16]:
    if target in haystack:
        print(target, "found")
        break
else:
    print("no match found")   # runs — 16 never matched
8 found
no match found

9. Summary

Mojo also supports the full set of augmented assignments: += -= *= /= //= %= **= @= &= |= ^= <<= >>= — each expands to its binary operation followed by assignment.

a % bRemainder; invariant a == b*(a//b) + (a%b)

& | ^ << >>Bitwise AND/OR/XOR/shifts; precedence ~, shifts, &, ^, |

📋 Chapter Summary:
  • Operator syntax mirrors Python — but integer / truncates instead of promoting to float.
  • ^ is XOR and the transfer sigil (Ch 7); ** is exponentiation.
  • Booleans use keywords with short-circuiting; truthiness comes from Boolable.
  • No match/switch yet — chain if/elif.
  • Iterate immutably by default; for ref to mutate through a reference.
  • for/else runs after full iteration, skipped on break/return.
