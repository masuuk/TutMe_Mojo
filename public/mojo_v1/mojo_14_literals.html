Chapter 14

🧩 Literals, Expressions & Statements

Every value written directly in source — integer bases, t-strings, escape sequences — plus the expression forms (tuples, comprehensions, walrus, comptime) and the statement grammar that holds a program together.

1. Literals

A literal is a value written directly in source code: 42, "hello", True. Literals produce values without reading variables or calling functions. Materialization makes a compile-time literal available at runtime — integer, floating-point, and string literals are implicitly materialized to Int, Float, and String.

Integer literals — four bases

42      # Decimal
0xFF    # Hexadecimal (0x or 0X prefix)
0o52    # Octal (0o or 0O prefix)
0b101010 # Binary (0b or 0B prefix)

1_000_000   # Readable grouping
1__000_     # Also valid — Mojo allows consecutive AND trailing underscores

Integer literals are always non-negative: -1024 is the unary negation operator applied to 1024. Leading zeros in decimal literals are not allowed — use 0o123 for octal. A base prefix must be followed by at least one digit (0x alone is an error).

Floating-point literals

1.0       3.14159    .5    # Fraction only (no integer part)
2.        2.5e-3     1E10  # Exponent; capital E works too
1_000.000_5               # Underscores as in integers

An exponent marker must be followed by at least one digit: 2.5e and 2.5e- are errors. Floats are also always non-negative.

Boolean, None, Self, and the ellipsis

  • True and False are the boolean literals.
  • None is the only value of type NoneType; a function without an explicit return type returns None.
  • Self (capital S) is a keyword referring to the enclosing type inside a struct or trait; self (lowercase) is just a conventional argument name.
  • ... marks a trait method as required — conforming types must implement it. It's only valid inside trait definitions, and it is not the same as pass: pass is a no-op body; ... means "you must implement this."
  • The underscore _ discards a value in an assignment: _, var y = get_pair().

2. String Literals & T-Strings

Mojo supports single and double quotes, and a triple-quote form for multi-line strings:

"Hello"  'world'
"""Multi-line string
"""                  # Includes final newline
"""\
No leading newline.""" # Backslash at end of line joins the next line

# Adjacent literals are joined into one string
var x = "Hello, " "World"       # "Hello, World"

# Raw strings: r or R disables escape processing
var path = r"C:\path\to\file"     # Backslashes literal

Mojo source files are UTF-8, so string literals may contain non-ASCII characters directly ("👋") or via hex escapes: \uHHHH for code points up to U+FFFF, \UHHHHHHHH for the full range. Both reject surrogate code points (U+D800–U+DFFF). The full escape set mirrors Python's: \n, \t, \\, \", \xHH, octal \0–\377, and friends.

T-string interpolation

T-string literals support expression interpolation with {}. Expressions inside the braces are evaluated at runtime, and adjacent t-string literals are joined like regular strings:

var name = "World"
var greeting = t"Hello, {name}!"     # "Hello, World!"
var result = t"1 + 1 = {1 + 1}"       # "1 + 1 = 2"
print(greeting)

# A t-string is its own type; cast to use it as a String
var greeting_str = String(greeting)

# Literal braces: {{ and }}
print(t"Use {{braces}} in t-strings")   # Use {braces} in t-strings
Hello, World!
Use {braces} in t-strings

T-strings can be triple-quoted and combined with the raw prefix in any order (rt"..."). They can be nested — an interpolation expression can itself contain t-strings, up to 20 levels deep:

var name = "world"
var greeting = t"Hello, {t" dear {name} "}!"
print(greeting)   # Hello, dear world!
Hello, dear world!

3. Expressions

An expression is any piece of code that produces a value. Beyond the obvious (identifiers, parentheses, calls, member access, subscripts), Mojo has several expression forms worth knowing cold.

Tuples

Commas create tuples, not parentheses:

var a = 2, 3          # tuple without parentheses
var b = (2, 3)        # same tuple with parentheses
var x, y = b            # x is 2, y is 3
()                      # empty tuple
(1,)                  # one-element tuple — the trailing comma matters
var point = (10, 20)
print(point[0])        # 10 — tuples support indexing
10

Collection displays

Displays are like literals but can contain expressions: [1, 1+1, 1+1+1]. List displays use brackets, dict displays use key: value pairs in braces, and set displays use braces without colons. Don't mix the two brace forms:

var numbers = [1, 2, 3]            # list — trailing commas OK
var ages = {"Alice": 30, "Bob": 25}  # dict
var primes = {2, 3, 5, 7}           # set

# {"a": 1, 2}  # Error: expected 'key: value' in dictionary expression
# {1, "b": 2}  # Error: cannot have a 'key: value' pair in set initializer
⚠️ Sharp Edge:

Brace syntax also serves as an initializer list — syntactic sugar for constructor calls, resolved at type-check time. var x: T = {} calls T(). And while set displays are core syntax, the Set type is not: import it with from std.collections import Set before using it as a type.

Calls, subscripts, and slices

Arguments before any keyword argument are positional; keyword arguments use name=value. Positional arguments can't follow keyword arguments, and keywords can't repeat. Colons inside square brackets create slices:

var items = [0, 1, 2, 3, 4, 5]
var first_three = items[0:3]    # [0, 1, 2] — stop not included
var from_three = items[3:]     # [3, 4, 5]
var every_other = items[::2]    # [0, 2, 4]
var reversed = items[::-1]    # [5, 4, 3, 2, 1, 0]
print(first_three, from_three, every_other, reversed)
[0, 1, 2] [3, 4, 5] [0, 2, 4] [5, 4, 3, 2, 1, 0]

Ternary conditional

The if–else expression selects between two values. It's right-associative and chains:

var label = "even" if x % 2 == 0 else "odd"

# Chains as: "small" if n < 10 else ("large" if n > 100 else "medium")
var size = ("small" if n < 10
            else "large" if n > 100
            else "medium")

The walrus operator :=

Regular assignments are statements, not expressions — they don't produce a value. The walrus operator is the expression form: it binds a value to a name and evaluates to that value:

var n: Int
if (n := len(items)) > 10:
    print(n)

var name: String
while (name := input("Prompt: ")) != "quit":
    print(name)
⚠️ Lowest Precedence:

The walrus binds looser than everything, so parenthesize: if item := list[idx] < 50 binds the comparison; if (item := list[idx]) < 50 binds the list item.

Compile-time expressions

comptime forces an expression to evaluate at compile time (parentheses required). Mojo also has built-in compile-time type expressions — type_of(x), conforms_to(T, Trait), and origin_of(x) — used for reflection and conditional conformance:

def heavy_calculation() -> Int:
    var sum = 0
    for i in range(1_000_000):
        sum += i
    return sum

# var x = comptime heavy_calculation()   # Error: requires parentheses
var x = comptime (heavy_calculation())  # O(1) at runtime
print(x)   # 499999500000
499999500000

4. Comprehensions

A comprehension builds a new collection by iterating over existing values and optionally filtering or transforming them — replacing loop-and-append patterns with a single expression:

# List: [expr for pattern in iterable if condition]
var squares = [x * x for x in [0, 1, 2, 3, 4] if x % 2 == 0]
# [0, 4, 16]

# Set: {expr for pattern in iterable if condition}
var fibs = {fib(x) for x in range(6)}   # {1, 2, 3, 5, 8} — deduped

# Dict: {key: value for pattern in iterable if condition}
var lengths: Dict[String, Int] =
    {k: len(k) for k in ["one", "two", "three"]}
# {one: 3, two: 3, three: 5}

print(squares)
[0, 4, 16]

Multiple for and if clauses are allowed and evaluate left to right — each for introduces a new iteration variable, each if filters on the current values:

var products = [(x, y, x * y)
              for x in range(3)
              for y in range(3)
              if (x + y) % 2 == 0]
# [(0, 0, 0), (0, 2, 0), (1, 1, 1), (2, 0, 0), (2, 2, 4)]

Because sets don't store duplicates, a set comprehension may produce fewer elements than iterations — the Fibonacci example yields 5 elements from 6 iterations.

5. Simple Statements

A simple statement performs a single action on one logical line; several can share a line when separated by semicolons.

Imports

Imports can appear at module level, inside functions, or inside other scopes — they don't need to be at the top of a file:

import std.math
from std.collections import Dict, Set

# Multi-line with parentheses — trailing comma is legal
from std.collections import (
    Dict,
    Set,
    List,
)

import numpy as np                          # Module alias
from std.collections import Dict as Dictionary # Name alias
from std.math import *                       # Wildcard

Assignment

Use var to declare new variables and ref to create reference bindings (a ref doesn't create a new value — writes through it write the referred-to element):

var x = 42                     # type inferred
var values: List[Float64] = []  # annotated
# var x                      # Error: needs a type or an initializer

ref y = my_list[3]           # reference binding — no copy

# Same value to several names (right-associative, RHS runs once)
var x = var y = var z = "Hello"

# Destructuring
var a, b = 1, 2
var e, f = returns_pair()

# Swaps need no temp
a, b = b, a

      

    


    
Augmented assignment (+=, -=, *=, /=, //=, %=, **=, @= matrix-multiply, plus the bitwise set) is sugar that evaluates the left-hand side once.


    
Expression statements and discards

    
An expression evaluated only for its side effects is an expression statement. When the result is unused (other than None) the compiler warns; assign it to _ to discard explicitly:


    

      

        
      

      

        
print("hello")   # returns None — no warning
x + y              # Warning: result is unused
_ = update()       # Explicitly discard the result

      

    


    
pass, return, raise, break, continue

    
    
      
  • pass is a no-op placeholder — required in empty function and struct bodies.
    • 
      
  • return exits a function, optionally with a value; a function without an explicit return returns None.
    • 
      
  • raise raises an error — the function must be declared raises or the call wrapped in try. A bare raise inside an except block re-raises the current error.
    • 
      
  • break exits the innermost loop; continue skips to the next iteration.
    • 
    


    
Compile-time declarations

    
comptime declares a compile-time constant; a trailing where clause constrains parameters and is checked at each use:


    

      

        
        
      

      

        
comptime SIZE = 256
comptime MAX = SIZE * 2

comptime AscendingMidpoint[lo: Int, hi: Int]: Int
    where lo < hi = (lo + hi) / 2

def main():
    comptime mid = AscendingMidpoint[2, 10]   # 6
    # comptime bad = AscendingMidpoint[10, 2]  # Error: lo < hi not satisfied
    print(mid)

      

      

        
6

      

    


    
comptime also declares associated types in traits and type aliases such as comptime Permissive = ImplicitlyCopyable & Deinitable.

  


  

    
6. Compound Statements

    
A compound statement has a header ending in : and an indented body. The first body statement sets the indentation for the rest; a later line with excess indentation is an error.


    
if / while / for

    
Conditions in an if/elif/else chain are evaluated in order; the first true one wins. Two Python shortcuts don't carry over:


    

      

        
      

      

        
if x > 0:
    print("positive")
elif x < 0:
    print("negative")
else:
    print("zero")

# These Python idioms do NOT work:
# x > 0 and print("positive")   # Error: 'None' isn't truthy
# print("positive") if x > 0 else pass  # Error: 'pass' isn't an expression

      

    


    
A for loop desugars to a while loop over __iter__() and __next__(), and destructuring works directly in the loop target (for key, value in pairs:).


    
Loop variable bindings

    
Loop variables are immutable references to the iterated items by default. Use var for a mutable copy, or ref to keep the element's own mutability:


    

      

        
        
      

      

        
var list: List[String] = ["a", "b", "c", "d"]

for var item in list:      # mutable copy — list unchanged
    item = item + "x"
    print(item)           # ax, bx, cx, dx
print(list)               # [a, b, c, d]

for ref item in list:      # reference — writes hit the list
    item = item + "x"
print(list)               # [ax, bx, cx, dx]

Loop else clauses

    
Both for and while support an else clause that runs when the loop exits normally — it does not run if the loop exited via break:


    

      

        
      

      

        
for item in items:
    if item == target:
        found = True
        break
else:
    print("not found")   # Only runs if break was never hit

      

    


    
try / except / else / finally

    
A try statement requires at least one except or finally clause; the full order is fixed:


    

      

        
      

      

        
try:
    operation()
except e:
    handle_error(e)   # Runs if an error occurs
else:
    on_success()      # Runs only if NO error occurred
finally:
    cleanup()         # Always runs last

# Typed errors: the bound variable's type is inferred
try:
    var result = fetch()
except e:            # e is inferred as the declared error type
    print(e.message)

      

    


    
A try block handles one error type; the compiler errors if the block could raise more than one. Without a binding, the error is caught but not accessible — there's no default error variable.


    
with — context managers

    
Cleanup always runs when the block exits, even on error. Multiple managers share one with:


    

      

        
        
      

      

        
with open("file.txt") as f:
    var content = f.read()

# A minimal custom context manager:
struct Scope (ImplicitlyCopyable):
    var label: String
    def __init__(out self, label: String):
        self.label = label
    def __enter__(self) -> Self:
        print("entering", self.label)
        return self
    def __exit__(self):
        print("exiting", self.label)

def main():
    with Scope("setup") as s:
        print("inside", s.label)

      

      

        
entering setup
inside setup
exiting setup

      

    


    
On entry, __enter__() runs and its result binds to the as target; on exit, __exit__() runs if it exists — even if an error occurred. __exit__ is optional; a manager defining only __enter__ is valid.


    
comptime if / comptime for

    
comptime if selects a branch at compile time, pruning the unselected branch from the compiled program. comptime for unrolls a loop — each iteration compiles as separate code, trading binary size for speed:


    

      

        
      

      

        
from std.sys import size_of

comptime if size_of[Int]() == 8:
    print("64-bit")
else:
    print("Probably 32-bit")

# Unrolls to: print(0); print(1); print(2)
comptime for i in range(3):
    print(i)

      

    


    
The condition or sequence must be a compile-time value — a runtime value in a comptime statement is a compile error. comptime if supports elif and else like the runtime form.


    
Scopes

    
Each compound statement body creates a new scope: variables declared inside aren't visible outside, as targets are scoped to their with block, and nested functions capture from enclosing scopes only through capture lists (Chapter 13).
